Public REST API (Version 1.0)

          
Direct endpoint references with authenticated examples.

          
          

            
               Swagger UI
            
            
               ReDoc Specification
            
          

        


        

          

            

              POST
              /v1/documents
            

            
Uploads a PDF or image file and initiates an asynchronous OCR processing job.

            
curl -X POST https://api.ocrlab.cloud/v1/documents \
  -H "Authorization: Bearer ocr_live_xxxxxxxxxxxxxxxx" \
  -F "file=@document.pdf" \
  -F "mode=auto"

          


          

            

              GET
              /v1/jobs/{id}/result
            

            
Retrieves structured OCR results in JSON (schema 1.0), Markdown, or plain text.

            
curl -X GET "https://api.ocrlab.cloud/v1/jobs/job_123/result?format=json" \
  -H "Authorization: Bearer ocr_live_xxxxxxxxxxxxxxxx"
